# sql-practice

This repository contains my SQL practice and university assignments completed using Microsoft SQL Server.

- Database creation and management
- SELECT, WHERE, ORDER BY, DISTINCT
- Filtering and sorting data
- Aggregate functions: COUNT, SUM, AVG, MIN, MAX
- GROUP BY and HAVING
- INNER JOIN
- Window functions
- Creating and modifying tables
- Constraints and data integrity

## Tools

- Microsoft SQL Server
- DBeaver
- Docker

The purpose of this repository is to document my SQL learning progress, practice database queries, and develop my skills in data analysis and IT analytics.
